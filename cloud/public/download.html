Install the local agent

The agent runs on any always-on machine on your home network (a laptop, a mini-PC, a Raspberry Pi). It scans your LAN and relays to this website. No Node.js required — these are standalone binaries.

After downloading

  1. Sign in to the dashboard and click “Pair a new agent” to get an 8-character code.
  2. Run the agent with that code: 
    ./performancehub-agent --server THIS-SITE --pair XXXX-XXXX
    On macOS you may need to allow it in System Settings → Privacy & Security. On Windows, click “More info → Run anyway” if SmartScreen prompts.
  3. The agent saves its pairing and reconnects automatically after that — just run it (no code needed) or install it as a service.

Prefer to run from source instead of a binary? See the agent/ folder in the repo.
